# AI 插件安全与产品边界

## 主程序保证

- AI 只能调用公开的 `IWorkflowAutomationApi`；禁止操作 `MainWindow`、`GraphCanvas` 或项目文件。
- 未注册算子、未知端口、越界参数、重复输入和环在提交前拒绝。
- 模型输出按不可信 JSON 处理，不执行其中的命令、代码、URL 或路径。
- AI 批量修改形成一个项目快照和一个撤销步骤。
- 项目修订冲突返回给 Agent，Agent重新读取摘要后才能重试。

## 插件与模型边界

- 插件程序集是受信任本机代码，不是安全沙箱；只安装可信来源和校验过 SHA-256 的插件。
- GGUF、mmproj、llama.cpp 和 CUDA 文件不进入主程序安装包，也不上传到普通项目。
- Provider 只允许启动配置的 `llama-server` 可执行文件，参数采用独立参数列表，不经过 Shell。
- 服务默认绑定 `127.0.0.1`，使用随机或配置端口；不得默认监听公网。
- 模型文件由用户选择或由标准模型目录下载；llama-server 由软件自动发现或安装，不接受项目内容覆盖全局路径。
- 本地与远程模型分别位于软件级配置目录的 `ai-local-models.json` 和 `ai-remote-models.json`。Windows 当前用户安装使用安装目录 `config`；Linux 使用 `$XDG_CONFIG_HOME/visionstudio`。远程 JSON 中除内部 ID 外，名称、端点、模型 ID、API Key 与能力参数均为密文；Windows 密文绑定当前系统用户，复制到其他用户/计算机后不能解密。
- 远程模型只通过用户配置的 OpenAI 兼容 Base URL 发送请求；界面必须明确区分本地、远程和标准版本地模型。
- 停止插件、切换模型或退出应用时只终止由当前插件启动并持有的进程。

## 视觉与测量边界

- VLM 用于场景理解、需求澄清和流程选择，不用于最终像素或物理测量。
- 裂纹计数受纹理、阴影、断裂间距和阈值影响，默认参数只是当前测试图基线。
- `PixelLength` 是检测路径的像素长度；不声明真实尺寸精度。
- 当前基线面向长横向暗裂纹；短裂纹、竖直裂纹、低对比、分叉或相交裂纹需要其他流程或后续算法版本。生产验收应建立标注数据集并报告精确率、召回率和长度误差。
- 没有 mmproj 时 Qwen2.5-VL GGUF只能作为文本规划模型使用，插件必须明确显示该降级状态。

## 当前不包含

- 静默安装 CUDA 或替用户接受第三方许可；标准模型下载前仍应向用户显示来源、大小、许可证与校验值；
- 多用户云端模型服务、账号计费或联网对话；
- 任意代码执行、终端工具、文件系统浏览和网络抓取工具；
- 无限制自治循环、后台持续修改工作流；
- 用 VLM 文字判断替代 OpenCV 数值测量；
- 插件热卸载后的程序集完全回收保证。
