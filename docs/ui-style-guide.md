# Vision Studio 界面规范

## 设计方向

界面采用 VS Code 的紧凑信息密度和 Visual Studio 的工具窗结构。目标是让画布保持最大面积，同时让命令、算子、结果、属性和状态各自拥有清晰层级。

## 工作台布局

```text
┌──────────────────────── 命令栏 ────────────────────────┐
│ 算子侧栏 │ 分隔栏 │        工作流画布       │ 检查器 │
│          │        │                         │ 结果   │
│          │        │                         │ 属性   │
├──────────────────────── 状态栏 ────────────────────────┤
```

- 命令栏与系统标题栏融合，高度 44 px；菜单靠左、算子搜索居中，并为右侧系统窗口按钮预留安全区域。
- 项目名移至底部蓝色状态栏左侧，完整路径继续通过悬浮提示提供。
- 保存、导出和关闭文件夹归入“文件”；撤销和自动排版归入“快捷操作”。
- “帮助 → 关于”显示软件名称、用途、版本和技术栈信息。
- 算子侧栏默认宽度 264 px，分类折叠、条目紧凑，并提供即时搜索。
- 中央画布占用全部剩余空间。
- 画布与节点强制裁剪在中央工作区内，并保持低于左右工具窗的绘制层级。
- 检查器默认宽度 356 px，结果和属性纵向排列；操作记录默认隐藏，由“视图”菜单控制。
- 左右侧栏以及结果/属性区域均允许拖动调整。
- 状态栏高度 22 px，使用品牌蓝显示当前反馈。
- 算子分类按视觉处理流程排序，“输入”固定在顶部，“输出”固定在末尾。
- 算子搜索匹配本地化名称、分类和接口名，搜索结果自动展开。
- 分类之间使用单像素分割线，不显示算子数量；二级算子项整行可点击，高度和间距统一。
- 操作记录显示时固定在属性区下方，不再使用底部折叠条。
- 未选择节点时，结果区和属性区显示简洁空状态，不显示上一节点的残留信息。

## 色彩

软件提供三套主题：黑色主题沿用默认 VS Code 风格；白色主题使用高对比浅色工作区；渐变主题采用低饱和深蓝紫渐变。主题切换必须同时覆盖 Fluent 控件、标题栏、侧栏、检查器、画布、网格、节点和状态栏，并持久化用户选择。

下表为默认黑色主题基准色：

| 用途 | 色值 |
|---|---|
| 应用背景 | `#181818` |
| 工作区/画布 | `#1E1E1E` |
| 侧栏 | `#252526` |
| 边框 | `#3C3C3C` |
| 主要文字 | `#D4D4D4` |
| 次要文字 | `#969696` |
| 品牌色/选中 | `#007ACC` |
| 悬停背景 | `#2A2D2E` |
| 输入端口 | `#6A9955` |
| 输出端口/连线 | `#4FC1FF` |
| 线路选中 | `#FFCC66` |

颜色应通过 `App.axaml` 资源引用，禁止在普通控件中随意增加近似色。画布绘制色集中在 `GraphCanvas`。

## 控件规则

- 普通按钮高度至少 30 px，圆角 3 px。
- 命令栏按钮使用 `toolbar` 样式；主操作叠加 `primary`。
- 算子条目使用 `operatorItem`，只在悬停时显示背景。
- 项目入口使用 `projectCard`，边框悬停时切换品牌蓝。
- 面板标题使用 `panelTitle`，字号 12 px、半粗体、全局统一。
- 输入框只在聚焦时显示品牌蓝边框。
- 不使用大面积渐变、强阴影或高饱和边框。

## 节点画布

- 节点主体使用 `#252526`，标题栏使用 `#333337`。
- 选中节点标题栏使用深蓝，边框使用品牌蓝。
- 节点左侧细色条表示分类，不改变端口颜色含义。
- 阴影只用于区分节点与画布，偏移和透明度保持克制。
- 网格分为 32 px 次网格和 160 px 主网格。
- 连线默认 1.8 px，悬停和选中仅增加有限宽度。

## 本地化与可访问性

- 视觉文本仍必须来自语言资源；皮肤不得引入只支持单一语言的固定标签。
- 重排布局时保留控件 `x:Name` 和自动化名称，避免破坏桌面回归。
- 用户路径可以截断显示，但不得修改或翻译实际值。
- 文字与背景应保持足够对比度，状态不能只依赖颜色表达。
