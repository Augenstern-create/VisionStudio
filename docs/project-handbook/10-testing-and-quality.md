# 测试与质量保障

## 1. 测试目标

测试不只回答“能不能编译”，而要回答：业务状态是否正确、用户入口是否可用、数据是否持久化、算法结果是否符合边界、发布包是否可安装和运行。

项目把证据分为三层：

1. **编译检查**：类型、依赖和 XAML 能生成；
2. **业务与状态测试**：直接验证图、缓存、文件、输出和异常；
3. **真实交互入口测试**：用鼠标、键盘、菜单、按钮和网络入口触发，再检查可观察结果。

任何交互修复不能只用第一层证明。

## 2. 测试维度

| 维度 | 重点 |
| --- | --- |
| UiStyle | 主题资源、布局、图标、颜色 |
| Typography | 字体、中英文资源、命名规范 |
| CanvasInteraction | 平移、节点、端口、线路命中与分支操作 |
| Workflow | DAG、端口、环、拓扑、代码生成契约 |
| Operators | OpenCV、参数、多端口、结构化结果、缓存 |
| Project | 新建、保存、目录、图片导入、文件关联 |
| RuntimeApp | 项目加载、输入源、结果映射、状态机、触发和有界队列 |
| Ai | 插件、模型配置、图片寻址、动作和计划 |
| DesktopInteraction | 页面和窗口生命周期 |
| Web | 鉴权、项目、上传、执行、文件、撤销、导出 |
| Packaging | Windows/Linux 安装、编辑器/CLI/Runtime 交付和系统集成 |
| EndToEnd | 跨模块完整桌面工作流 |

修改后只运行受影响维度；发布候选或公共基础设施变化才执行 All。这减少无关测试成本，同时要求修复用户场景时必须加入原始复现输入。

## 3. 单元与集成测试

xUnit 覆盖：

- 重复 ID、未知端口、类型不匹配、重复输入和环；
- 目标节点执行切片和确定性顺序；
- 项目目录、Unicode 路径、原子保存和路径越界；
- 常用 OpenCV 算子、通道、结构化输出和缓存失效；
- C# 生成结果可编译；
- AI JSON、动作白名单、重复流程唯一 ID、图片编号、上下文隔离、插件加载和远程密钥加密；
- Web 存储和自动化会话。
- Runtime 单次/连续执行、输入源、状态转换、手动/定时触发、队列容量和丢帧统计。

## 4. 真实 UI 测试

`test-ui-workflows.ps1` 启动真实桌面程序并执行项目创建、菜单、主题、语言、关于、设置、节点点击、属性修改、缓存、Ctrl+Z、连接右键、导出和关闭文件夹。

测试采用 UIAutomation 和原生鼠标事件。例如标题栏修复不是检查是否绑定了事件，而是实际拖动并比较窗口坐标；主题边框不是只看 XAML，而是切换三种主题后采样屏幕像素。

`test-ai-second-image-project.ps1` 直接打开 DemoProject，确认旧对话存在，实际发送 IMG-02 指令、等待本地模型、检查最新建议来源、点击应用，再读取保存工作流确认首线来自 IMG-02 而不是 IMG-01。

## 5. 确定性 AI 测试与实机测试

日常回归使用固定 Provider 或本地假 OpenAI 端点，确保响应可重复、无需互联网且不会因模型随机性误判。实机模型测试单独运行，用于验证插件、llama-server、GGUF 和真实 UI 闭环，但它不能替代确定性测试。

## 6. Web 与发布测试

Web 脚本启动服务并验证健康、令牌、项目、上传、快照、修改、执行、预览、撤销、导出和路径限制；单元测试还验证损坏项目日志及并发取消隔离。安装测试验证 Windows 安装/运行/关联/卸载，以及 Windows/Linux 主包中的编辑器、CLI、Runtime 和 DEB 元数据、权限、启动器、图标、MIME。

## 7. 算法精度测试与功能测试的区别

功能测试可以断言 Count 是非负整数、长度是有限数、预览存在；精度测试必须有人工标注真值和容差。没有标注时，不能把某次输出 38 个候选、2550.3 px 描述成真实裂纹数量和长度。

正式场景应建立：

- 检测级标注：目标实例、缺陷类别；
- 几何级标注：中心线、端点、轮廓或物理尺寸；
- 数据分层：材质、光照、方向、对比度、批次；
- 指标门禁：Precision/Recall/F1、长度误差、P95 延迟；
- 版本记录：代码、工作流、参数、标定和数据集版本。

## 8. 如何回答“你们怎么保证质量”

标准回答应包括：强类型和校验在运行前阻止非法图；缓存和项目系统有状态测试；OpenCV 有集成测试；用户入口有真实 UI 自动化；AI 有确定性 Provider 和实机闭环两类测试；发布包有安装验证；算法精度则必须针对客户数据另建标注集，不用单图结果冒充精度保证。
