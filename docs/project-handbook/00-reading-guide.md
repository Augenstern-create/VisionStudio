## 三种讲解深度

### 30 秒版本

Vision Studio 是一个面向工业视觉算法设计和验证的可视化 OpenCV 工作流工具。用户用节点连接图像处理步骤、调整参数并即时查看结果；同一工作流可以由桌面端、Web、CLI 和自动化 API 使用，还能通过可选 AI 插件把自然语言需求转换为受校验的算子流程。它的核心价值是把视觉算法从零散代码变成可观察、可复用、可测试、可导出的工程资产。

### 3 分钟版本

重点说明四件事：

- 它不是单纯的 OpenCV 示例程序，而是一个强类型 DAG 工作流引擎。
- 节点只描述算法和参数，执行、缓存、项目文件、UI 与 AI 接入彼此解耦。
- AI 不直接控制鼠标，也不直接改项目 JSON，只能提交白名单 Graph Action，经端口、参数、环和修订版本校验后由核心 API 应用。
- 桌面端适合本地交互，Web 端在服务器执行 OpenCV，CLI 适合自动化；模型和 llama.cpp 作为可选插件分发，不让主安装包膨胀。

### 30 分钟版本

按照本手册第 01、02、04、07、10、11 章展开，并用 `samples/DemoProject` 演示：加载图像 → 多阶段裂纹流程 → 查看结构化输出 → 修改参数触发局部重算 → AI 指定 IMG-02 生成新分支 → 撤销或保存。

## 阅读时必须牢记的边界

- “140+ 算子契约”不等于每个算子都达到工业生产精度；部分高级标定、卡尺、特征和 AI 节点仍是基础实现或稳定接口。
- 像素长度不是毫米长度；没有标定就不能承诺物理测量精度。
- AI 的职责是理解需求和规划流程，最终图像计算仍由 OpenCV 算子执行。
- 插件是本机受信任代码，不是安全沙箱；模型输出才按不可信数据处理。
- 当前 Web 鉴权适合内部单租户部署，多租户公网产品还需要账号、角色、审计与项目级授权。
