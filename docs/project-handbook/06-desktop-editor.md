# 桌面编辑器实现

## 1. 工作台布局

桌面端采用 VS Code 风格活动栏与 Visual Studio 风格工具窗：顶部融合标题栏和菜单，中间只保留画布，左侧活动栏在算子与 AI 之间切换，右侧上方显示结果、下方显示属性，底部状态栏反馈项目和执行状态。

启动时先进入项目页，用户选择新建或打开后才进入编辑器。关闭文件夹返回项目页，而不是退出进程。

## 2. GraphCanvas 为什么是自绘控件

节点数量、连线命中、画布缩放和平移需要统一坐标系。`GraphCanvas` 负责：

- 绘制主/次网格、节点、端口、阴影和连线；
- 屏幕坐标与画布坐标转换；
- 鼠标平移、节点拖动、端口拖线和线路选择；
- 正交直线加圆角转弯；
- 节点、端口和线路的宽命中区域；
- 自动排版和下游分支选择、整理、删除；
- 生成 UIAutomation 节点，供自动化测试和可访问性使用。

自绘能保持大量节点下的一致视觉和交互，但需要自行维护命中、裁剪、DPI 和自动化 Peer。

## 3. 连线规则

视觉线路使用水平/垂直正交段，高低差通过圆角转弯连接。显示线较细，命中带明显更宽，因此用户不必精准点中 1～2 像素。建立连接时依据真实端口定义判断兼容性；一个输入已有连接时不会再接受第二条输入。

右键线路可以选择、重新排版或删除该连接之后的整个下游分支，解决大型流程逐节点操作的问题。

## 4. 属性与结果

节点选择事件触发属性区重建。属性控件根据参数定义生成数字、布尔、文本或文件选择入口；修改参数记录撤销、标记项目脏状态、自动保存，并调度当前节点执行。

结果预览支持适应窗口、滚轮缩放和拖动。预览位于右侧，避免压缩中央画布。重复点击同一节点会更新选择和结果，不重新绑定易崩溃资源。

## 5. 主题与本地化

`UiThemeManager` 将深色、浅色和渐变主题写入动态资源。普通控件、标题栏、活动栏、侧栏、画布、节点和状态栏分别引用语义色，而不是散落硬编码近似色。

中英文文本来自 JSON 资源。算子在画布和菜单中显示本地化名称，属性显示稳定接口名。英文资源测试会检查键完整性和中文残留，方便继续扩展其他语言。

## 6. 自定义标题栏

窗口扩展内容到系统装饰区域。顶部空白区注册为原生 `TitleBar` 命中角色，菜单和搜索框注册为 `User` 交互角色；同时保留 `BeginMoveDrag` 回退。这样既能拖动窗口，又不会让搜索框和菜单吞掉或触发移动。

## 7. ChatMessageControl

AI 对话不是普通不可选中的 TextBlock，而是专门控件：

- 用户与助手使用不同聊天气泡；
- 普通文本使用可选择文本，可复制；
- Markdown 风格代码块独立渲染，并提供“复制代码”；
- 支持引用，把选中消息转成引用文本插入输入框；
- 自定义 AutomationPeer 将完整消息暴露给 UIAutomation；
- 长消息在对话滚动区内显示，错误也作为独立助手消息保存。

## 8. 撤销与自动保存

画布在修改前发出 `WorkflowChanging`，主窗口记录撤销快照；修改后发出 `WorkflowChanged`，触发脏状态、AI 图片引用刷新和必要的执行。操作记录写入项目后台，可由“视图”选择显示。自动保存与操作记录更新结合，降低意外退出的数据丢失风险。

## 9. 可访问性和真实测试

关键按钮、画布节点、提示框、对话记录和菜单都有 Automation Name。PowerShell UIAutomation 脚本通过实际鼠标、菜单、键盘和按钮验证标题栏拖动、主题像素、节点双击、连线右键、AI 发送/应用、Ctrl+Z 和关闭文件夹，而不是只调用后台方法。
